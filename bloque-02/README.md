# Bloque 2 — Intermedio: manipulación de arreglos

Tiempo objetivo: **65 minutos**.

Este bloque practica los patrones más rentables para Junior: recorrer un arreglo, crear otro con `push`, evitar repetidos con `includes`, conservar el orden y trabajar con posiciones consecutivas.

Orden sugerido: 1 → 2 → 3 → 4 → 5. Si te atoras más de 12 minutos, anota el punto donde te detuviste y pasa al siguiente; volveremos después.

## Recordatorio de JavaScript

```js
const resultado = [];
resultado.push(valor);        // agrega al final
resultado.includes(valor);    // true si el valor ya existe
lista.length                  // cantidad de elementos
```

No uses entrada por teclado ni `console.log` como respuesta. El juez llamará la función y verificará su `return`.
